# Rogue Galaxy PC port

A native PC port of *Rogue Galaxy* (PS2, North America, SCUS-97490 v1.01) for Windows and
Linux. It is not an emulator: the game's code comes from a matching decompilation and is
compiled for the PC, with native graphics (Direct3D 11 / Vulkan), audio, input, saves and
movies.

**You need your own copy of the game.** The downloads contain no game content; setup
rebuilds everything from your own disc image.

## Play

| | Download | Steps |
| --- | --- | --- |
| Windows 10/11 | `release/RogueGalaxyPC-1112b-win32.zip` | Unzip, put your `.iso` in the folder, run `Setup.exe` once, then `rg-game.exe`. See [QUICKSTART.md](QUICKSTART.md). |
| Linux x86-64 (Vulkan, X11 or Wayland) | `release/RogueGalaxyPC-1112b-linux-x86_64.zip` | Unzip, put your `.iso` in the folder, run `./rg-setup` once, then `./rg-game`. See [QUICKSTART-linux.md](QUICKSTART-linux.md). |

Build 1112b (2026-11-12). Automated tests reach every story boss on both platforms; please
report bugs with the steps that led there.

## Features

- **Display:** windowed or fullscreen, internal resolution up to 8x, widescreen (16:9,
  16:10, 21:9) with menus and HUD laid out for the wider screen, frame rates up to 240 or
  uncapped, anti-aliasing, anisotropic filtering, and enhanced bloom, depth of field and shadows.
  The memory-card screens use the full width too.
- **HD texture packs:** dump and replace textures (PCSX2-compatible names).
- **Controls:** keyboard, mouse and any gamepad, fully rebindable, with button prompts
  matching your device.
- **Audio:** separate volumes and output device selection.
- **Options:** text speed, battle speed-up, UI scale, colour-blind modes and reduced
  flashing; inventory sorting.
- **Insectron:** copy and paste Insectron passwords.
- **Online Battle:** Insectron 2-Player Battle over LAN, a VPN or a forwarded port (TCP 7490).
- **Saves:** stored as files with automatic backups; import from a PCSX2 memory card.
- **Settings menu:** F1 (or hold Back + Start). An "Original" preset restores the PS2 look
  and behaviour.

## Notes

- Windows SmartScreen warns about the unsigned executables: choose "More info", then "Run
  anyway".
- If the game crashes on Windows, please attach `rg-game-crash.txt` and `rg-game-crash.dmp`
  (next to the game) to your report.

## Supported disc

Rogue Galaxy (USA), SCUS-97490 v1.01: 6,967,721,984 bytes, SHA-1
`87377e721be58e8b6a5a7501721563500d237df7`. Other versions are refused by setup.

## How the download avoids game content

Every byte of the built executable that matches the retail game is zeroed before
packaging, and a table records only where each run comes from. Setup verifies your disc,
copies those bytes back from it, and checks the result's SHA-256 before writing the
executable.

## Building from source

This branch also holds the port's source, so others can build and change it.

| Path | Contents |
| --- | --- |
| `game/` | The game's decompiled C, as the port compiles it: generated by `tools/ingest.py` from a snapshot of the matching decompilation, with the port's transform stages applied. Never edited by hand. Its data tables hold placeholders (below). |
| `overrides/` | Hand-ported replacements for single `game/` files, each recording the hash of the file it replaces |
| `src/` | The PC side: native renderer (D3D11 / Vulkan), audio, file system, threads, pad, saves, settings, host shell (SDL3), the Sony SDK surface the game calls, `rg-extract` / `Setup.exe` |
| `include/`, `cmake/`, `CMakeLists.txt` | Port headers and the build |
| `pregen/` | Build inputs normally generated from the decomp snapshot: the overlay registry and `DATAFILL.tsv` (the files that hold data placeholders) |
| `missing/` | Stand-ins for functions the snapshot calls but does not define |
| `tests/` | Unit tests (`ctest`) |
| `third_party/` | Vendored single-header libraries (see THIRD_PARTY_NOTICES.md) |
| `tools/` | The build script, the data fill, the ingest stages and the scripts the tests run |

### Requirements (Windows)

Put these in a `tools` folder next to the repository (or point `RG_TOOLS` at it; `LLVM_ROOT`
overrides the LLVM folder):

```
workspace/
  port/        this repository
  tools/
    llvm/                              LLVM/Clang 23 (official Windows release, extracted)
    ninja/ninja.exe                    Ninja 1.13
    cmake-3.31.7-windows-x86_64/       CMake 3.31 (portable zip)
    dxc/bin/x64/dxc.exe                DirectX Shader Compiler with SPIR-V (python tools/native/fetch_dxc.py)
    dl/SDL3-3.4.18.tar.gz              optional: SDL3 source for offline builds (else downloaded)
```

Also needed: Visual Studio 2022 Build Tools (MSVC 14.44: the x86 C runtime and the Windows SDK) and Python 3.10+.

### First build

1. Extract your disc with `Setup.exe` from the release zip, or with `rg-extract`:
   `rg-extract "Rogue Galaxy (USA).iso" -o data` in the repository root.
2. Fill in the game data: `python tools/gamedata_fill.py --data data`. The published `game/`
   and `overrides/` hold placeholders instead of the game's data values; this puts them back
   from your own disc and checks every file's SHA-256. In a git checkout it marks the filled
   files skip-worktree: they now hold game data, so never commit them.
3. Build: `powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Game` (i686, Clang +
   Ninja; the same options as the release build).
4. Run `build\i686-windows\rg-game.exe --data data`.

Run the unit tests with `ctest --test-dir build\i686-windows`. Some tests need files that are
not part of this repository (save-state fixtures, traces) and skip or fail without them.
