# overrides/

Hand-ported replacements for individual `game/` files. `game/` itself is generated by
`tools/ingest.py` and is never edited; when a file cannot be made to compile or behave
through a port header or an ingest stage rule, its replacement goes here.

## Convention

- **Path:** `overrides/<relpath>` replaces `game/<relpath>` (same relative path, e.g.
  `overrides/src/main/map/MapAreaInit_1dcf90.c` replaces
  `game/src/main/map/MapAreaInit_1dcf90.c`).
- **Header:** within its first 4 KiB the override must carry the SHA-256 of the
  *generated* `game/` file it replaces (the value in `game/MANIFEST.tsv`, i.e. after all
  ingest stages), plus a reason:

  ```c
  /* rg-override: replaces game/src/main/map/MapAreaInit_1dcf90.c sha256 <64 hex>
   * why: <one line: what the stages could not do> */
  ```

- **Start from the generated file**, not from the decomp source: copy `game/<relpath>`,
  then edit. Keep the diff small so a re-port after a snapshot bump is mechanical.
- **Prefer a stage rule or a port header** (`include/port/`) when the same fix applies to
  more than one file.

A function the snapshot **calls but does not define** has no `game/` file to
replace, so it cannot be an override: it goes under `missing/` instead
(`missing/README.md`), and is dropped automatically once the snapshot defines it.

## Checks

- `python tools/ingest.py --check` (and every ingest run) verifies each override: the
  header exists, names its own path, the target is in `MANIFEST.tsv`, and the recorded
  hash equals the current one. A mismatch is reported `STALE`: the snapshot or a stage
  changed the file underneath, so re-port the override and update the hash.
- `tools/gamesrcs.py` (run by CMake at configure) compiles `overrides/<relpath>` in place
  of `game/<relpath>`. Re-configure after adding or removing an override.

## Port-provided game files

`PORT_PROVIDED.tsv` lists game files that are NOT compiled because a port module
provides their symbol (SDK hardware/kernel functions, host-CRT libc names);
`tools/gamesrcs.py` skips them. docs/LINK.md "Providers".
